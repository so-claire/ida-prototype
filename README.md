# Data Portal · prototype (static)

Static build of the Data Portal web app (branch `feat/catalog-v3`, commit 73fa796) on the fictional demo dataset `content/demo` (`[DEMO]`, `congty.example`).
API responses were captured from the local fake-data demo for 4 personas (Mass, Operation, Manager, Data Team); switch persona in the avatar menu.
No backend, no real data, no real permission checks, no `/exec`. Source code is kept in a private repository.
